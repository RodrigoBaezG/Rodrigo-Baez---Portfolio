FinAlly — AI Trading Workstation

A dark, data-dense trading dashboard with live price streaming over Server-Sent Events, a simulated $10k portfolio with market orders, and portfolio heatmap and P&L charts. An LLM chat assistant analyzes holdings and can execute trades from natural-language requests. Packaged as a single Docker container (Next.js static export + FastAPI, SQLite storage).

  • FastAPI
  • SSE
  • AI / LLM
  • Docker

Prelegal — AI Legal Drafting

A SaaS app for drafting professional legal agreements through a conversation. The AI assistant identifies the document type (11 templates, including NDAs and cloud service agreements), gathers the required fields, and fills a live preview as you talk. Users can sign in, save drafts, reopen them later, and download a PDF. Structured LLM outputs keep the extracted fields reliable.

  • Next.js
  • FastAPI
  • AI / LLM
  • Docker

Goals App

A goal tracker for setting daily, weekly, monthly or yearly targets, logging progress with one click, and watching a progress bar fill up. Users sign up and log in with JWT-based authentication; passwords are hashed with bcrypt. The REST API runs on Express with PostgreSQL, and the backend is covered by Supertest integration tests. A demo mode lets visitors explore the UI without an account.

  • Vite
  • Node.js
  • Express
  • PostgreSQL
  • JWT

Art Gallery

A website for a visual artist to showcase and catalog paintings, drawings and digital illustration. Visitors browse works by category, open a detail page for each piece with its technique and description, and can view the commissions page. The catalog is served from a REST API backed by PostgreSQL, so new works can be added without touching the front end.

CV Editor

A résumé builder with a form-based editor and a live preview that updates as you type. Application state is managed with React Context and a reducer, the form fields are reusable components, and the finished CV can be exported to PDF. Unit tests cover the reducer and components with Vitest and Testing Library.
